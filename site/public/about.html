THE RELEASE MODEL

Know what changed.
Know who approved it.

This is the second page of the release-5 static artifact. All assets use relative paths, so the site can open through a path-style or subdomain IPFS gateway without a rebuild.

Immutable artifacts

A directory CID identifies the entire site. A canonical manifest lists every file with its size, MIME type, and SHA-256 digest. If any byte changes, that evidence no longer describes the same artifact.

Separate authority

ENSure separates preview publishing from production approval. ENSv2 permissions are part of the security boundary: the build publisher should have preview rights, not production rights.

Independent verification

The separate verifier reads live chain records, checks the approval evidence, fetches the manifest and site, and compares the raw bytes. This static page does not run those checks and does not claim a verified status.

What integrity does not mean

Matching an owner's approval is not a code audit. An owner can approve a flawed release, and an owner compromise remains outside this protection.
